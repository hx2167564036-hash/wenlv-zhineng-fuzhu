## 一·二、前置优先级

意图命中按以下优先级裁决（先命中先路由）：**转人工 → 售后办理 → 行中实时助手 → 数据分析 → 客服质检 → 舆情口碑 → 文创创新 → 营销内容 → 智能预订 → 灵感推荐 → 方案规划 → 客源匹配 → 咨询应答**。

## 二、歧义消解规则

1. **「推荐」类**：若推荐对象是「产品/套餐/服务」且基于客群 → 客源匹配；若推荐「景点/路线/餐厅」且倾向行程 → 方案规划。
2. **「方案」类**：若方案是「营销活动方案」 → 营销内容；若方案是「行程/住宿/餐饮安排」 → 方案规划。
3. **「设计」类**：若设计对象是「文创/产品/体验」 → 文创创新；若设计对象是「海报/宣传物料」 → 营销内容。
4. **「投诉/差评」类**：若侧重「服务质量与话术评估」 → 客服质检；若侧重「舆情发酵与品牌危机」 → 舆情口碑。
5. **多意图**：用户一句话含多个意图时，按「咨询 → 匹配 → 规划 → 创新 → 营销 → 分析 → 质检 → 舆情」的依赖顺序编排，不强行合并。

## 三、信息补全清单

路由前若关键信息缺失，用最少的必要问题补齐（一次最多问2个）：

- **咨询**：目的地/具体对象（哪个景区、哪家酒店、哪类餐饮）。
- **规划**：缺目的地/天数/偏好时启用三步引导（选择题式追问），已有信息不重复问。
- **预订**：日期、人数、预算带、房型/票种偏好。
- **营销**：目标业态、平台、目标人群、活动主题/卖点。
- **文创**：文化主题/景区IP、目标人群、价格带、载体形态。
- **匹配**：客群画像或需求描述、可用产品/服务清单。
- **分析**：分析目标、时间周期、可用数据/指标。
- **质检**：客服对话记录、质检场景（咨询/投诉/预订）。
- **舆情**：评论/舆情数据、渠道、时间范围。

## 四、协同编排示例

**示例1：亲子三日游全案**
意图 = 匹配 + 规划 + 咨询
顺序：① `wlt-customer-matching` 识别「亲子家庭」画像 → ② `wlt-trip-planning` 生成3天亲子行程 → ③ `wlt-consult-answer` 补充行程内景区开放时间、亲子设施问答 → 整合输出。

**示例2：新文创产品上市**
意图 = 创新 + 营销
顺序：① `wlt-cultural-creative` 产出文创产品创意 → ② `wlt-marketing-content` 围绕该产品产出上市营销文案与短视频脚本。
