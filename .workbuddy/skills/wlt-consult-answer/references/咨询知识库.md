# 文旅咨询知识库

按三大业态组织的高频咨询条目与标准应答要点。所有价格/时间/政策为**示例数据**，应答时须提醒「以官方为准」。

## 一、景区咨询条目

### 1. 开放时间
- 应答要点：常态开放时间 + 节假日延长/夜游时段 + 停止售票/入园截止时间。
- 示例：「该景区旺季（4–10月）8:30–17:30开放，17:00停止入园；夜间演艺季延至21:00。」

### 2. 门票与优惠
- 应答要点：票种（全价/半价/套票）、优惠人群（学生/老人/军人/儿童身高标准）、预约与退改规则。
- 示例：「全价票¥120，学生及60–69岁老人半价，70岁以上免票；需提前1天在公众号实名预约，未使用可退。」

### 3. 导览与路线
- 应答要点：推荐游览动线、必看点位、建议游览时长、讲解服务（人工/电子导览/AR）。
- 引导：结合客群（亲子选互动馆、摄影选观景台）。

### 4. 交通与配套
- 应答要点：公共交通、自驾停车位与费用、接驳车、无障碍/母婴室/寄存位置。

### 5. 适游度
- 应答要点：亲子（婴儿车是否友好）、老人（台阶/坡度/轮椅）、天气影响与最佳季节。

## 二、酒店咨询条目

### 1. 房型与价格
- 应答要点：房型分类、床型/面积/景观/可住人数、是否含早、会员价。
- 示例：「家庭套房含1.8米大床+1.2米小床，可住3–4人，含3早，周末¥880起。」

### 2. 入住退房
- 应答要点：入住/退房时间、延迟退房政策、押金、证件要求。

### 3. 设施与服务
- 应答要点：泳池/健身房/亲子乐园/会议室开放时间、早餐时段、接送机、行李寄存、叫醒。

### 4. 特殊政策
- 应答要点：加床费、是否可带宠物、儿童早餐标准、取消/改期政策。

## 三、餐饮咨询条目

### 1. 招牌菜推荐
- 应答要点：按口味（辣/清淡）、人数、预算推荐，说明食材与特色。
- 引导：招牌菜 + 配菜 + 主食的合理搭配建议。

### 2. 预订与排队
- 应答要点：是否可预订、包厢、等位时长、营业时段（午市/晚市/夜宵）。

### 3. 口味与忌口
- 应答要点：辣度/甜度可选、素食/清真/过敏原适配、儿童餐。

## 四、标准应答示例

**问**：「带5岁孩子去你们景区方便吗？门票怎么买？」

**答**（示范结构）：
> 亲子出游该景区比较友好。门票方面，1.2米以下儿童免票，成人¥120，可在公众号提前1天实名预约、未用可退。设施上，景区提供婴儿车租赁（¥30/天）与母婴室，主游览线多为平缓步道，适合推婴儿车。建议上午9点前入园避开客流高峰，亲子互动馆和萌宠乐园是孩子的最爱。需要我帮您规划半日亲子游览动线吗？

**要点复盘**：直接回答（方便+购票）→ 关键细节（免票/租赁/母婴室）→ 体验建议（避开高峰/亲子点位）→ 引导下一步（规划动线）。
