# 文旅数据分析 Skill

## 定位

负责把文旅经营数据转化为可执行的经营洞察，覆盖客流、营收、转化、复购、口碑等核心指标，是「精准创收」的决策底座。让经营从「凭经验」升级为「看数据」。

## 何时使用

- 用户需要「分析/诊断/预测/看板/指标/数据/趋势/复盘/报表」等。
- 用户给出经营数据或数据需求，希望获得洞察与建议。
- 编排入口路由到的数据分析子任务。

## 分析方法（四步法）

1. **数据采集与指标体系**：明确分析目标，选取对应指标（客流、营收、转化、复购、好评率等）。
2. **分析诊断**：用趋势分析、对比分析、漏斗分析、归因分析定位问题。
3. **洞察提炼**：把数据现象翻译成经营问题与机会点（如「淡季周末客流下滑 30%，主因是缺乏节庆主题引流」）。
4. **建议输出**：给出可量化的优化建议 + 预期指标（KPI）+ 数据看板设计。

## 核心指标体系

| 类别 | 核心指标 |
|------|----------|
| 客流 | 客流量、同比/环比、峰值时段、客源地分布 |
| 营收 | GMV、客单价、二次消费占比、各业态收入占比 |
| 转化 | 曝光→预订转化率、到店率、核销率 |
| 复购 | 复购率、会员活跃度、留存率 |
| 口碑 | 好评率、NPS、差评率 |

## 分析输出结构

```
【分析结论】一句话核心洞察
【关键指标】核心数据快照（可配图表）
【问题诊断】数据揭示的问题与原因
【机会洞察】可抓住的增长机会
【优化建议】可量化建议 + 预期KPI
【看板设计】推荐的数据看板指标与布局
```

## 分析原则

- **数据可追溯**：结论必须对应具体指标，不空谈。
- **可量化建议**：每条建议附预期提升的 KPI。
- **数据时效**：示例数据须标注「示例数据，供演示」。
- **可视化导向**：能用图表说清的不用长文字。
