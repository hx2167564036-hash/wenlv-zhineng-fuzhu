# 客群画像与匹配规则

含四维标签体系、产品标签化示例、匹配度计算方法与推荐示例。

## 一、客群画像四维标签体系

### 人口属性
- 亲子家庭（儿童年龄：0–3 / 3–6 / 6–12）
- 情侣 / 新婚夫妇
- 银发（60+，区分健康活跃型/需照护型）
- 商务人士
- 学生 / 年轻人（Z世代）
- 独行旅客

### 出行场景
- 亲子出游、蜜月度假、研学旅行、公司团建、家庭聚餐、商务宴请、毕业旅行、避暑/避寒度假

### 消费偏好
- 高性价比、品质体验、打卡社交、文化深度、美食探索、休闲放松、运动户外

### 预算价格带
- 经济（人均 <¥300/天）、中端（¥300–800/天）、高端（>¥800/天）

## 二、产品/服务标签化示例

以文旅产品为例，为每个产品打标签：

| 产品/服务 | 标签 |
|-----------|------|
| 亲子主题房（含早） | 亲子家庭、亲子出游、中端、品质体验 |
| 蜜月观景套房 | 情侣、蜜月、高端、品质体验 |
| 景区亲子套票 | 亲子家庭、亲子出游、经济、高性价比 |
| 非遗研学营 | 学生、研学旅行、中端、文化深度 |
| 商务会议套餐 | 商务、商务宴请、中端、品质体验 |
| 夜游演艺票 | 年轻人/情侣、打卡社交、经济 |

## 三、匹配度计算规则

1. **硬约束优先**：预算价格带不匹配 → 直接排除或降级。
2. **标签重合计分**：人口属性命中 +2 分，出行场景命中 +2 分，消费偏好命中 +1 分，价格带命中 +1 分。
3. **排序**：按总分降序排列；同分时按「价格带适配度 > 场景匹配 > 偏好匹配」二次排序。
4. **组合推荐**：总分相近的多项可打包为套餐，提升客单价。

## 四、推荐输出示例

**需求**：「一对情侣周末想来放松，预算中端，喜欢拍照打卡」

**画像标签**：情侣 / 打卡社交 / 中端 / 休闲放松

**推荐清单**（示例）：
1. **蜜月观景套房 + 夜游演艺套票** — 标签命中「情侣+打卡社交+中端」；理由：景观房适合拍照出片，夜游演艺是社交爆款，套票省心。
2. **古镇写真旅拍套餐** — 命中「情侣+打卡社交」；理由：提供服装与跟拍，满足出片需求。
3. **温泉汤屋下午茶** — 命中「情侣+休闲放松+中端」；理由：私密放松，符合周末放空诉求。

**行动建议**：首推「套房+演艺」组合，可再叠加写真套餐形成「住+玩+拍」一站式。
