# 文旅客源精准匹配 Skill

## 定位

负责把「客群画像」与「产品/服务」精准连接，是提升客源转化效率、实现「精准创收」的核心能力。让推荐从「拍脑袋」变为「有据可依」。

## 何时使用

- 用户请求「推荐/适合/匹配」文旅产品、套餐或服务。
- 用户给出客群特征或需求描述，希望获得精准推荐。
- 需要构建客群画像或做需求洞察。
- 编排入口路由到的匹配子任务。

## 匹配方法（四步法）

1. **画像构建**：从需求描述提取客群标签（人口属性、出行场景、消费偏好、预算、兴趣）。
2. **产品标签化**：将可用产品/服务打上对应标签（适配客群、主题、价格带、场景）。
3. **规则匹配**：用「标签重合度」计算匹配度，优先推荐高重合产品。
4. **推荐输出**：给出推荐清单 + 匹配理由 + 差异化说明 + 下一步动作。

## 客群画像标签体系（四维）

| 维度 | 标签示例 |
|------|----------|
| 人口属性 | 亲子家庭 / 情侣 / 银发 / 商务 / 学生 / 独行 |
| 出行场景 | 亲子出游 / 蜜月 / 研学 / 团建 / 家庭聚餐 / 商务宴请 |
| 消费偏好 | 高性价比 / 品质体验 / 打卡社交 / 文化深度 / 美食探索 |
| 预算价格带 | 经济 / 中端 / 高端 |

详细标签体系与匹配规则见 `references/画像与匹配规则.md`。

## 推荐输出结构

```
【客群画像】提炼的标签摘要
【推荐清单】按匹配度排序的 3–5 项产品/服务
   每项：名称 / 匹配标签 / 推荐理由 / 价格带（示例）
【差异说明】首推 vs 备选的取舍
【行动建议】预订入口 / 组合建议 / 关联推荐
```

## 匹配原则

- **证据先行**：每条推荐都给出「为什么适合」，而非只给名称。
- **组合思维**：优先推荐「套餐/组合」而非单品，提升客单价。
- **替代方案**：高匹配无货/超预算时，给次优替代。
- **数据标注**：价格与库存为示例数据，标注「以官方为准」。
