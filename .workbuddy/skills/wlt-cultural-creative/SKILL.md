# 文旅文创与服务产品创新 Skill

## 定位

负责把景区/酒店/餐饮的文化资源转化为有记忆点、可消费的文创产品与服务体验，破解「产品同质化、迭代滞后」的行业痛点，激活二次消费与品牌价值。

## 何时使用

- 用户需要「文创/创意/设计/伴手礼/纪念品/周边/特色产品/创新/体验升级」等。
- 用户给出文化主题或景区IP，希望孵化文创产品。
- 编排入口路由到的创新子任务。

## 创新方法（五步法）

1. **文化提炼**：从目的地提取可用的文化符号（地标、非遗、传说、方言、美食、纹样、色彩）。
2. **需求洞察**：明确目标人群（游客/本地人/年轻人/亲子/收藏者）与消费场景（自用/送礼/收藏）。
3. **创意发散**：用「文化符号 × 载体形态 × 功能价值」矩阵交叉产生创意。
4. **可行性筛选**：从成本、工艺、量产、版权、安全维度筛选可落地创意。
5. **方案成型**：输出产品定义（名称/形态/材质/定价/包装）+ 故事文案 + 落地要点。

## 创意矩阵

```
        载体形态（明信片/冰箱贴/盲盒/文具/香氛/食品/服饰/家居/数字藏品）
文化符号 × 功能价值（纪念/实用/社交/收藏/情绪治愈）
        ↓
        产生若干创意组合，逐一提炼命名与卖点
```

## 产品方案输出结构

```
【产品名称】一句话命名（易记、有文化感）
【产品定位】目标人群 + 消费场景 + 价格带
【产品形态】载体 + 材质 + 尺寸 + 工艺
【文化故事】融入的文化符号与故事叙事
【差异化卖点】与市面上同类产品的区别
【落地要点】成本/量产/版权/安全
【营销联动】可配合的营销内容（可衔接营销Skill）
```

## 创新原则

- **拒绝「贴标签」式文创**：文化元素要融入功能与体验，而非简单印在商品上。
- **情绪价值优先**：文创的本质是「把回忆带回家」，强化情感与社交传播属性。
- **系列化思维**：单品要有延展成系列的潜力（IP化、盲盒化、联名化）。
- **可落地**：考虑量产成本与定价，避免「创意很美、卖不动」。
