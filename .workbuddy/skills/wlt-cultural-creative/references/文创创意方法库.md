# 文创创意方法库

含文化符号提炼方法、载体形态清单、创意矩阵用法、案例与落地清单。

## 一、文化符号提炼清单

从目的地提取可用的文化元素：

| 类别 | 可提炼元素示例 |
|------|----------------|
| 地标 | 标志性建筑、山形、塔、桥、门楼剪影 |
| 非遗 | 刺绣、剪纸、漆器、皮影、戏曲、茶艺 |
| 传说故事 | 民间传说、历史人物、典故 |
| 方言/文字 | 本地俚语、地名谐音梗 |
| 美食 | 特色小吃、老字号、时令食材 |
| 纹样色彩 | 传统纹样、器物配色、服饰图案 |
| 自然 | 特色动植物、地貌、气候（云雾/雪景） |

## 二、载体形态清单

- **纸品**：明信片、手账贴纸、笔记本、书签、贺卡、纸雕灯。
- **桌面小物**：冰箱贴、钥匙扣、徽章、摆件、盲盒、积木。
- **文具**：钢笔/中性笔、尺子、橡皮、文件夹、帆布袋。
- **香氛个护**：香薰、护手霜、手工皂、香包。
- **食品**：联名糕点、茶饮、伴手礼礼盒、文创雪糕。
- **服饰配饰**：丝巾、T恤、帆布鞋、首饰、手机壳。
- **家居**：抱枕、马克杯、桌垫、香薰灯、地毯。
- **数字藏品**：NFT、AR明信片、线上打卡徽章。

## 三、创意矩阵示例（以「古镇」为例）

文化符号 = 古镇屋檐、石板路、非遗扎染、方言「巴适」
载体 × 功能交叉：

- 屋檐纹样 × 帆布袋（实用）→「檐下时光」帆布袋，印屋檐剪影 + 方言 slogan。
- 石板路 × 盲盒（收藏）→「巷弄」系列迷你路牌盲盒，集齐一条街。
- 扎染 × 香囊（情绪）→ 非遗扎染香囊，附手作体验券。
- 方言 × 冰箱贴（社交）→「巴适得很」方言冰箱贴，打卡社交爆款。

## 四、落地可行性清单

- [ ] 成本可控：量产单价 ≤ 定价的 25%。
- [ ] 工艺可实现：材质与工艺有成熟供应链。
- [ ] 版权合规：文化符号无侵权（非遗/文物元素需授权或公共领域）。
- [ ] 安全合规：食品/个护需资质；儿童用品符合安全标准。
- [ ] 物流友好：尺寸重量适合携带与邮寄。
- [ ] 有故事可讲：能包装成有情感的文化叙事。

## 五、案例范式

**案例：故宫文创（范式参考）**
- 模式：文物纹样 → 生活化载体（胶带、口红、书签）→ 情感叙事（「故宫的礼物」）。
- 启示：文化符号要「降维」到生活场景，让用户觉得「好看又实用」，而非「仅供观赏」。

**示例方案：某茶园景区「一叶知春」文创雪糕**
- 产品名称：一叶知春（茶文化 + 节气）
- 定位：游客打卡、亲子、18–35岁；¥25–35 价格带
- 形态：抹茶/茉莉口味雪糕，造型为茶树嫩芽，附可收藏的「节气书签」棒
- 文化故事：以「谷雨采茶」非遗技艺为叙事，雪糕棒印节气文案，集齐24节气可兑换
- 差异化：可食用 + 可收藏（棒签系列化）+ 打卡传播属性
- 落地：与本地老字号茶企联名，季节限定，配短视频种草（衔接营销Skill）
