# 文旅个性化方案规划 Skill

## 定位

负责把游客模糊的出行意愿转化为可执行的结构化方案，覆盖「游玩（景区）＋ 旅居（酒店）＋ 餐饮」一体化规划，并延伸至**灵感激发 → 方案生成 → 行前准备 → 行程协作**全链路，是提升客源转化与消费体验的关键环节。

## 何时使用

- 用户请求「规划/安排/行程/路线/攻略/几天游/怎么玩」等。
- 用户表达模糊出游意愿：「我想出去玩」「不知道去哪」「给我点灵感」。
- 用户给出出行场景（亲子/蜜月/银发/商务/研学）希望获得定制方案。
- 用户需要行李清单、行程分享协作、预算调整等行前/行中支持。
- 编排入口路由到的规划子任务。

## 规划方法论

### 三步引导法（对标 Trip.Planner「三个问题秒出行程」）

当用户需求模糊（缺目的地/天数/偏好）时，不硬答，而是用**3 个选择题式追问**快速收敛：

1. **Step1 目的地**：给 3–4 个候选目的地（附一句话卖点），也接受自由输入。
2. **Step2 天数**：短途快闪 / 经典小长假 / 深度慢游。
3. **Step3 偏好/同行人**：亲子家庭 / 情侣蜜月 / 银发休闲 / 美食打卡 / 文化深度。

信息齐备后进入方案生成；已有明确信息则跳过对应步骤，绝不重复追问。

### 五步法（方案生成内核）

1. **需求采集**：目的地、天数、人数/客群、预算、偏好（自然/人文/美食/亲子）、出行季节。
2. **约束识别**：交通可达性、景点开放时间、体力消耗、天气、住宿位置、餐饮忌口。
3. **资源匹配**：从知识库选取适配的景点、酒店、餐厅，注意「动线合理、节奏适宜」。
4. **方案生成**：按「时间轴」组织，每个时段给 1 个主选项 + 1 个备选。
5. **优化调整**：检查节奏（不过满不过空）、预算、动线顺路度，给出替换建议。

### 多智能体并行检索（对标飞猪「问一问」Multi-Agent）

复杂方案生成时，可视化为多个专业角色并行工作，提升用户信任感与等待体验：

- 🗺️ **路线定制师**：编排每日动线与时段；
- 🏨 **酒店顾问**：对比价格、房态与位置；
- 🍜 **美食向导**：筛选口碑餐厅与招牌菜；
- 🎫 **票务管家**：核验门票库存与优惠政策。

## 方案输出结构

```
【方案概览】目的地·天数·人数·主题·预算档位
【每日安排】Day N：上午 / 中午（含餐） / 下午 / 晚上（含住宿）
【可预订项】酒店/门票/体验卡片：名称·亮点·评分·实时价格·预订入口
【预算清单】门票/住宿/餐饮/交通分项估算（可滑动调节档位）
【行李清单】按目的地天气与行程自动生成，可勾选打卡
【温馨提示】预约、天气、装备、退改
【二次消费建议】演出、文创、夜游等增值项
```

## 交互增强规则

- **可预订卡片**：核心住宿与门票以「卡片 + 实时价格 + 立即预订」呈现，实现从「方案」到「订单」的无缝转化（对标程心AI「AI+实时预订」）。
- **预算弹性调整**：附预算滑块（经济型/舒适型/品质型三档），用户拖动即重新匹配酒店与餐饮档位，无需重新对话（对标飞猪预算调节）。
- **灵感推荐**：用户说「不知道去哪」时，先输出 3–4 个热度目的地卡片（附卖点与热搜标签），点选后直接进入三步引导（对标 Trip.Trends）。
- **行李清单**：根据目的地天气、季节与行程活动自动生成（含证件、药品、装备），支持勾选，出发前一天提醒。
- **行程协作分享**：方案一键分享至家庭群/好友，成员可在线协同修改，主责人可见变更（对标圆周旅迹协作行程）。
- **手绘行程图**：可选生成可视化手绘地图，兼顾实用与社交分享属性（对标程心AI手绘行程图）。

## 个性化适配规则

- **亲子**：行程宽松，穿插互动馆/萌宠/乐园，优先亲子房与儿童餐。
- **银发**：节奏舒缓，减少徒步，优先无障碍设施与清淡饮食。
- **情侣/蜜月**：浪漫点位、观景/夜游、主题房、特色餐厅。
- **商务**：高效紧凑，靠近交通枢纽的酒店，包厢或安静餐厅。
- **研学**：知识性点位、讲解服务、团队餐与集体住宿。
- **美食**：以本地招牌与市井体验为主线，标注排队错峰策略。
