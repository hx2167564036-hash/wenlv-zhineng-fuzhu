# 营销内容模板库

含平台调性、爆款结构、文案/脚本/活动模板与示例。价格为示例数据。

## 一、平台调性对照

| 平台 | 调性 | 内容偏好 | 黄金结构 |
|------|------|----------|----------|
| 小红书 | 真实种草、精致 | 攻略、清单、真实体验 | 标题钩子 → 场景 → 分点干货 → 互动引导 |
| 公众号 | 深度、有故事 | 长图文、专题、人物故事 | 情感切入 → 层层递进 → 干货 → 转化 |
| 抖音 | 强节奏、娱乐化 | 3秒钩子、反转、短平快 | 钩子 → 主体 → 反转 → CTA |
| 朋友圈 | 信任、私域 | 短文案、优惠、熟人推荐 | 一句话卖点 + 时间/名额稀缺 + 链接 |

## 二、爆款标题公式

- **数字+人群+结果**：「带娃3天玩遍XX，这份攻略请收好」
- **痛点+方案**：「不想人挤人？XX景区错峰玩法全攻略」
- **悬念/反差**：「本地人都不愿告诉你的XX隐藏玩法」
- **利益诱导**：「暑期亲子套票低至¥199，含餐含住宿」

## 三、小红书图文文案模板

```
【标题】数字 + 人群 + 结果

【正文】
开头（痛点/场景）：还在纠结周末去哪？
种草（体验）：上周带娃去了XX……
干货（分点）：
1. 门票/交通
2. 必玩点位
3. 避坑提示
结尾（互动）：还有想知道的评论区问我～

【话题标签】#亲子游 #周末去哪儿 #XX景区
```

## 四、短视频脚本模板（分镜表）

| 镜号 | 画面 | 台词/字幕 | 时长 |
|------|------|-----------|------|
| 1 | 航拍景区全景 | 3秒钩子：「99%的人不知道的XX秘境」 | 3s |
| 2 | 游客体验特写 | 场景代入：「周末带娃，一天刚刚好」 | 5s |
| 3 | 分点卖点快切 | 卖点1/2/3 字幕卡 | 6s |
| 4 | 优惠/行动号召 | 「戳左下角，抢暑期早鸟票」 | 4s |

## 五、活动策划模板

```
【活动主题】____（一句话，含利益点）
【活动目标】曝光/种草/预订/到店（可量化KPI）
【目标人群】____
【玩法机制】参与方式 + 奖励设计（打卡/集章/抽奖/拼团）
【传播设计】预热（悬念）→ 爆发（话题+达人）→ 长尾（UGC沉淀）
【预算】____
【预期指标】曝光量 / 参与量 / 转化量
```

## 六、成品示例（暑期亲子主题）

**小红书文案示例**：
> **带娃3天玩遍梦幻谷，这份攻略请收好**
>
> 纠结暑假去哪？上周末刚带娃实测梦幻谷，好玩不累还省心！
> 1. 门票：1.2米以下免票，成人¥150，公众号提前预约（以官方为准）；
> 2. 必玩：萌宠乐园（上午人少）、水上乐园（下午凉快）、夜光巡游（19:30）；
> 3. 避坑：租婴儿车¥30/天，早点租；餐厅11点前入座不用排队。
> 还有想知道的评论区问我～
>
> #亲子游 #暑期出行 #梦幻谷

**转化引导语**：「戳下方链接，抢暑期亲子早鸟票，数量有限先到先得！」
