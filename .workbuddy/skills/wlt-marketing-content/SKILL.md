# 文旅营销内容生成 Skill

## 定位

负责把文旅产品/服务的卖点转化为高转化的营销内容，覆盖图文、短视频脚本与活动策划，降低获客成本、提升转化效率。

## 何时使用

- 用户需要「文案/宣传/推广/海报/短视频/脚本/种草/活动策划」等。
- 用户给出产品/服务卖点，希望产出可投放内容。
- 编排入口路由到的营销子任务。

## 生成方法（四步法）

1. **明确目标与人群**：转化目标（曝光/种草/预订/到店）、目标人群（亲子/情侣/银发/商务）。
2. **提炼核心卖点**：用「FAB 法则」——Feature（特性）→ Advantage（优势）→ Benefit（利益/情绪价值）。
3. **选对平台与调性**：小红书重「种草+真实感」、公众号重「深度+故事」、抖音重「3秒钩子+强节奏」、朋友圈重「短平快+信任」。
4. **套用爆款结构**：钩子（前3秒/首句）→ 场景代入 → 卖点证据 → 行动号召。

## 内容形态与结构

### 图文文案（小红书/公众号）
- 标题公式：数字 + 人群 + 结果（「带娃3天玩遍XX，这份攻略请收好」）。
- 正文结构：痛点切入 → 场景种草 → 分点干货/卖点 → 结尾引导互动。

### 短视频脚本
- 结构：黄金3秒钩子 → 内容主体（每3–5秒一个信息点）→ 反转/彩蛋 → 行动号召。
- 分镜要素：画面 / 台词 / 字幕 / 时长。

### 活动策划
- 结构：活动主题 → 目标 → 人群 → 玩法机制 → 传播设计 → 预算 → 预期指标（KPI）。

## 输出规范

- 直接给成品，不给「建议怎么写」的说明。
- 文案附平台标签（#话题），短视频脚本用分镜表格。
- 价格/优惠为示例数据，标注「以官方为准」。
- 结尾附「转化引导语」。
