# 文旅舆情口碑管理 Skill

## 定位

负责文旅品牌的舆情监测与口碑管理，及时发现负面舆情、把握舆论风向、保护品牌声誉，是「服务质感」与「品牌资产」的守门人。

## 何时使用

- 用户需要「舆情/口碑/差评/好评/危机/公关/舆情监测/品牌声誉/负面」等。
- 用户提供评论数据或舆情信息，希望分析口碑或制定应对策略。
- 编排入口路由到的舆情子任务。

## 管理方法（四步法）

1. **舆情采集**：汇总多渠道口碑（OTA 评论、社交平台、点评、投诉）。
2. **情感分析**：将评论分为正面/中性/负面，提取高频关键词与情绪趋势。
3. **口碑诊断**：定位好评亮点与差评痛点，计算口碑健康度。
4. **应对策略**：区分危机等级，制定差评应对、正面口碑放大、危机公关策略。

## 情感分析维度

- **情感极性**：正面 / 中性 / 负面占比。
- **高频关键词**：好评关键词（「值得」「好玩」「贴心」）、差评关键词（「排队」「贵」「态度」）。
- **情绪趋势**：正面/负面情绪随时间的变化曲线。
- **口碑健康度**：综合好评率、NPS、负面处置率的健康评分。

## 输出结构

```
【口碑概览】口碑健康度 + 情感分布（正面/中性/负面占比）
【好评亮点】高频好评关键词与可放大点
【差评痛点】高频差评问题与原因归类
【舆情预警】待处置负面舆情清单（按危机等级）
【应对策略】差评应对 + 正面放大 + 危机公关方案
```

## 应对原则

- **分级响应**：一般差评「24小时回应」、集中负面「48小时专项」、重大危机「即时响应+统一口径」。
- **先共情后解决**：回应先表达歉意与重视，再给解决方案。
- **放大正面**：主动引导好评、沉淀 UGC 作为营销素材。
- **口径统一**：危机时统一对外口径，避免信息混乱。

详细分级与应对模板见 `references/舆情分级与应对.md`。
