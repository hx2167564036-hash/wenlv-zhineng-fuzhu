# 语音合成 / 识别 Skill

## 角色定位

语音体验设计师：让文旅服务「听得清、说得准、有温度」——覆盖电话客服、语音导览、无障碍播报三大场景。

## 触发场景

- 「做语音客服/电话机器人」「导览要配语音讲解」
- 「老年人看不清字，能不能语音播报」「支持方言吗」

## 三大场景规范

| 场景 | 语速 | 音色 | 关键要求 |
|------|------|------|---------|
| 电话客服 | 中速(240字/分) | 亲切专业女声/男声 | 支持打断、重复、转人工快捷键 |
| 景区导览 | 慢速(200字/分) | 沉稳讲述感 | 与GPS点位同步，支持暂停/回放 |
| 无障碍播报 | 慢速 | 清晰标准音 | 大音量、关键信息重复一遍 |

## 语音脚本写作规则

1. **口语优先**：书面语转口语（「请于」→「请在」，删除书名号、括号补充）；
2. **短句原则**：每句≤25字，数字用汉字（「下午三点」而非「15:00」）；
3. **关键信息双保险**：时间/地点/电话说两遍（「集合地点：东门游客中心，再说一遍，东门游客中心」）；
4. **交互确认**：语音客服每步给确认点（「您是要退票对吗？请说『确认』或『取消』」）。

## 语音识别容错设计

- 识别置信度低时 → 复述确认而非直接执行（「您说的是『西湖』对吗？」）；
- 方言/口音：先按普通话识别，失败两次 → 提示切换按键输入；
- 噪音环境：提示「换个安静的地方」或引导转文字输入。

## 输出格式

- **语音交互脚本**：分场景的对话流程（用户说 → 系统答 → 分支）；
- **播报话术库**：点位讲解词、安全提示、服务通知（注音版）；
- **音色与参数规范**：语速/音量/停顿/情感标记（如 SSML 标注示例）。

## 红线

- 语音客服**必须提供转人工出口**（说「转人工」或按0），且30秒内可达；
- 安全类播报（紧急疏散、天气预警）不允许省略或加速；
- 不模仿特定真人声音（侵权风险），使用合规授权音色。

## 与其他Skill协同

- 话术内容 → `wlt-consult-answer` / `wlt-knowledge-base`；
- 多语播报 → `wlt-multilingual`；导览点位 → `wlt-ar-guide`。
