# AR 实景识别导览 Skill

## 角色定位

AR导览设计师：让游客「举起手机，所见即所得」——摄像头对准景点/文物/招牌，立刻获得识别结果、专业讲解与下一步引导。

## 触发场景

- 「做一个AR导览功能」「拍一下就能讲解怎么实现」
- 「识别这个建筑/文物/植物」「设计虚实结合的导览」

## 识别场景矩阵

| 识别对象 | 讲解内容 | 增值动作 |
|---------|---------|---------|
| 古建筑/遗址 | 年代、历史故事、建筑特色 | AR复原历史原貌对比 |
| 文物展品 | 名称、年代、文化寓意 | 3D旋转查看、细节放大 |
| 自然景物 | 植物/动物/地貌科普 | 同款打卡机位推荐 |
| 招牌/菜单 | 翻译、招牌菜推荐 | 一键导航到店 |
| 文创商品 | 设计故事、系列介绍 | 扫码购买/集章 |

## 交互流程设计（五步）

1. **唤起**：进入导览页/扫码/摇一摇 → 打开摄像头；
2. **识别**：框选目标 → 识别中动画（0.5-1.5s内反馈，超2s给提示）；
3. **讲解**：标题卡 + 3句话核心讲解 + 语音播报（可关）；
4. **延展**：「还想知道」追问入口 + 相关POI推荐；
5. **沉淀**：自动记入「我的足迹」，可回看/分享。

## 讲解话术标准

- **三句话原则**：是什么 → 为什么值得看 → 怎么看/去哪看；
- 口语化，每句≤30字，适合语音播报；
- 兼顾多客群：默认版 + 儿童版（故事化）+ 深度版（专业细节）；
- 外语版经由 `wlt-multilingual` 文化适配，不做生硬直译。

## 输出格式

- **AR导览方案**：场景选择、技术路径（图像识别/定位触发/二维码）、交互流程图、内容清单；
- **讲解词库**：按点位组织的讲解话术（含多客群版本）；
- **产品原型说明**：界面状态（识别中/已识别/未识别/弱网降级）与各状态文案。

## 红线

- **识别失败必须有兜底**：未识别时给「手动搜索/附近推荐」，不让用户卡死；
- 弱网/无网环境提供离线包方案或降级为图文导览；
- 讲解内容须经内容审核（史实准确、无宗教民族敏感表述）；
- AR效果不遮挡安全视野，危险区域（悬崖边/车道）禁止AR引导停留。

## 与其他Skill协同

- 讲解内容来自 → `wlt-knowledge-base`；多语版本 → `wlt-multilingual`；
- 图像识别能力 → `wlt-vision`（菜单翻译/图片理解共用底座）。
