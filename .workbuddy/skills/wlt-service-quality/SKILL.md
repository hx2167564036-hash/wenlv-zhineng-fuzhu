# 智能客服质检 Skill

## 定位

负责对文旅客服的服务质量进行自动化质检与优化，破解「人工服务刻板、服务质量不稳定」的痛点，是「服务质感」的保障层。

## 何时使用

- 用户需要「质检/评分/话术/服务标准/投诉/红线/服务质量/复盘」等。
- 用户提供客服对话记录，希望评估质量或优化话术。
- 编排入口路由到的质检子任务。

## 质检方法（五步法）

1. **明确质检维度**：专业度、态度、效率、合规、转化（五维）。
2. **评分**：按维度打分（1–5 分），加权计算总分与等级。
3. **问题定位**：标出扣分点与「红线问题」（违规承诺、态度恶劣、答非所问）。
4. **改进建议**：针对问题给出优化话术与话术模板。
5. **输出报告**：质检评分卡 + 问题清单 + 优化建议。

## 五维质检标准

| 维度 | 权重 | 考察要点 |
|------|------|----------|
| 专业度 | 30% | 信息准确、知识扎实、无错答 |
| 态度 | 25% | 礼貌热情、有耐心、有温度 |
| 效率 | 20% | 响应及时、直击要点、不绕弯 |
| 合规 | 15% | 无违规承诺、无红线话术 |
| 转化 | 10% | 自然引导预订/二次消费 |

## 输出结构

```
【质检结论】总分 + 等级（优秀/良好/及格/待改进）
【五维评分】雷达式评分（专业度/态度/效率/合规/转化）
【问题清单】逐条标注问题话术 + 扣分原因
【红线预警】是否存在红线问题（若有，高亮）
【优化建议】改进话术 + 标准话术模板
```

## 质检原则

- **证据化**：每个扣分点必须引用原话术。
- **红线零容忍**：违规承诺、歧视、态度恶劣等问题一票否决。
- **可落地**：改进建议直接给可用的标准话术。

详细标准与话术模板见 `references/质检标准与话术.md`。
