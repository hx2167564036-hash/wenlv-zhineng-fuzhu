# 文旅全场景智能辅助 Skill 系统 · 实训方案

面向 **旅游管理、文化创意、数字媒体** 等相关专业的实训教学设计。学生通过「理解架构 → 体验系统 → 拆解机制 → 动手扩展」四阶段，掌握 AI Coding 驱动的文旅智能化应用能力。

## 一、实训目标

| 维度 | 目标 |
|------|------|
| 知识 | 理解文旅三大业态痛点、五条业务线能力、Skill 协同机制 |
| 技能 | 掌握意图识别、方案规划、营销内容生成、文创创新、客源匹配的方法论 |
| 素养 | 培养「以客群为中心、以数据为据、以体验为导向」的运营思维 |

## 二、实训总时长建议

共 **12 学时**（每学时 45 分钟），可拆分为 4 个模块，灵活组合。

| 模块 | 内容 | 学时 |
|------|------|------|
| 模块一 | 系统认知与体验 | 2 |
| 模块二 | 意图识别与路由机制拆解 | 3 |
| 模块三 | 八条业务线方法论实训 | 5 |
| 模块四 | Skill 扩展与项目实战 | 2 |

## 三、分模块实训设计

### 模块一：系统认知与体验（2 学时）

1. 讲解文旅行业三大痛点与系统价值主张（智能适配、创新迭代、精准创收）。
2. 打开 `demo/index.html`，学生自由体验五大场景（切换业务线 + 输入自然语言）。
3. 观察「路由标签」，理解每次请求背后触发了哪个 Skill。
4. **任务**：每人记录 5 条「输入 → 识别意图 → 路由结果」，小组讨论识别是否准确。

### 模块二：意图识别与路由机制拆解（3 学时）

1. 阅读 `wlt-tourism-assistant/SKILL.md` 与 `references/意图路由规则.md`。
2. 讲解关键词 + 语义双重匹配规则、歧义消解规则、多意图协同编排。
3. **任务**：给定 10 条混合请求，学生手工标注意图并说明依据，对照系统结果纠偏。
4. 进阶：分析「多意图」请求（如「亲子3日游全案」）的 Skill 协同顺序。

### 模块三：八条业务线方法论实训（5 学时）

前五条（游客与产品侧）各 0.8 学时重点实训，后三条（经营与保障侧）合 1 学时拓展实训，采用「方法讲解 + 案例分析 + 实操产出」：

| 业务线 | 方法 | 实训产出 |
|--------|------|----------|
| 咨询应答 | 先答后引、客群适配、多轮追问、转人工机制 | 3 条标准应答话术 + 1 组追问补全设计 |
| 方案规划 | 三步引导法、五步法、可预订项组织 | 1 份 3 日游方案（含可预订项与预算三档） |
| 营销内容 | FAB 法则、爆款结构 | 1 篇小红书文案 + 1 个短视频脚本 |
| 文创创新 | 创意矩阵、可行性筛选 | 1 个文创产品提案 |
| 客源匹配 | 四维标签、重合计分 | 1 份推荐清单 |
| 数据分析 | 指标体系、四步诊断 | 1 份经营诊断报告 |
| 客服质检 | 五维质检、红线标准 | 1 份质检评分卡 |
| 舆情口碑 | 情感分析、危机分级 | 1 份口碑诊断与应对方案 |

**对标实训专题**（结合 Demo 新增交互能力）：分析主流旅行 AI 产品（携程 TripGenie、飞猪问一问、同程程心AI）的功能设计，拆解「三步引导、多智能体可视化、可预订卡片、行中实时助手、转人工机制」背后的用户需求逻辑，撰写 1 份体验对比评测报告。

### 模块四：Skill 扩展与项目实战（3 学时）

1. 讲解 Skill 结构（SKILL.md 的 frontmatter + 正文 + references 渐进式披露）。
2. **任务**：每组选择一个方向扩展系统，如：
   - 新增一个业务 Skill（如「文旅数据分析」「智能客服质检」）；
   - 为现有 Skill 补充 references（如新增某景区的咨询知识库）；
   - 优化 Demo 的意图识别规则或响应内容。
3. 成果汇报：演示扩展效果 + 说明设计思路。

## 四、考核与评价

| 评价项 | 权重 | 标准 |
|--------|------|------|
| 机制理解 | 30% | 能准确解释意图识别与路由、多Skill协同机制 |
| 方法应用 | 40% | 五条业务线方法论能正确产出符合规范的成果 |
| 创新扩展 | 30% | Skill 扩展方向合理、可落地、有创意 |

## 五、专业适配说明

- **旅游管理**：侧重方案规划、客源匹配、数据分析、服务流程优化，理解智能技术如何提升运营效率与服务质量。
- **文化创意**：侧重文创产品创新方法论（文化提炼、创意矩阵、可行性筛选），培养文化资源的商业化转化能力。
- **数字媒体**：侧重营销内容生成（平台调性、爆款结构、脚本分镜）与舆情口碑管理，培养文旅内容策划与品牌传播技能。
