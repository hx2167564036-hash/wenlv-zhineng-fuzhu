# 文旅全场景智能辅助 Skill 系统

> 基于 AI Coding 引擎的文旅智能辅助系统，通过轻量化智能 Skill 协同，实现文旅场景智能咨询应答、个性化游玩旅居餐饮方案规划、营销内容生成、特色文创与服务产品创新赋能、客源需求精准匹配、文旅数据分析、智能客服质检、舆情口碑管理，覆盖景区服务、酒店旅居、餐饮消费、文旅营销、产品研发、经营决策全业务场景。

## 项目背景与目标

针对文旅行业景区、酒店、餐饮三大核心业态的三大痛点：

| 痛点 | 现状 | 系统解法 |
|------|------|----------|
| 消费体验同质化 | 人工服务刻板、千篇一律 | 智能咨询 + 个性化方案 + 质检保障，千人千面 |
| 客源转化效率低 | 需求适配度低、获客成本高 | 客源精准匹配 + 精准营销内容 |
| 产品创新迭代慢 | 固化产品、迭代滞后 | 文创与服务产品创新赋能 |

**核心目标**：将传统「人工服务、固化产品、被动经营」的文旅运营模式，重构为「**智能适配、创新迭代、精准创收**」。

## 系统架构

系统由 **1 个编排入口 + 8 个业务 Skill + 共享知识库** 组成，采用「意图识别 → 任务路由 → 多Skill协同 → 结果整合」的轻量协同机制。

```
┌──────────────────────────────────────────────────────────┐
│            编排入口  wlt-tourism-assistant                 │
│       意图识别 · 任务路由 · 多Skill协同 · 结果整合           │
└──┬──────┬──────┬──────┬──────┬──────┬──────┬──────┬───────┘
   │      │      │      │      │      │      │      │
 ①咨询  ②规划  ③营销  ④文创  ⑤匹配  ⑥数据  ⑦质检  ⑧舆情
   └──────┴──────┴──────┴──────┴──────┴──────┴──────┘
           共享知识库（景区/酒店/餐饮知识·话术·产品·指标）
```

**八条业务线**分两大板块：
- **游客与产品侧**：① 咨询应答 ② 方案规划 ③ 营销内容 ④ 文创创新 ⑤ 客源匹配
- **经营与保障侧**：⑥ 数据分析 ⑦ 客服质检 ⑧ 舆情口碑

## 快速开始

1. **体验 Demo**：浏览器打开 `demo/index.html`，点击 Bento 业务线卡片或直接输入自然语言。
2. **使用 Skill**：本项目级 Skill 已安装在 `.workbuddy/skills/`，在 WorkBuddy 对话中提出文旅相关请求（如「分析暑期营收下滑原因」）即可触发编排入口并路由到对应业务 Skill。
3. **阅读文档**：查看 `docs/` 下的架构设计与实训方案。
